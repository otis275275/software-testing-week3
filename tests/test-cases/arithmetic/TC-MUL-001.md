## Mục tiêu

Xác minh hệ thống nhân chính xác hai giá trị số hợp lệ.

## Điều kiện tiên quyết

- Truy cập được trang Basic Calculator.
- Chọn build cần kiểm thử.
- Nhấn **Clear**.

## Dữ liệu kiểm thử

| Trường | Giá trị |
|---|---|
| First number | 6 |
| Second number | 7 |
| Operation | Multiply |
| Integers only | Unchecked |

| 2 | Nhập `7` vào Second number | Giá trị hiển thị đúng |
| 3 | Chọn Multiply | Multiply được chọn |

# TC-ADD-001 — Cộng hai số hợp lệ

## Thông tin chung

| Thuộc tính | Nội dung |
|---|---|
| Test Case ID | TC-ADD-001 |
| Chức năng | Add |
| Mức độ ưu tiên | High |
| Người tạo | [Tên thành viên] |
| Ngày tạo | YYYY-MM-DD |

## Mục tiêu

Xác minh hệ thống cộng chính xác hai giá trị số hợp lệ.

## Điều kiện tiên quyết

- Truy cập được trang Basic Calculator.
- Chọn build cần kiểm thử.
- Nhấn **Clear** để đưa ứng dụng về trạng thái ban đầu.

## Dữ liệu kiểm thử

| Trường | Giá trị |
|---|---|
| First number | 10 |
| Second number | 5 |
| Operation | Add |
| Integers only | Unchecked |

## Các bước thực hiện

| Bước | Thao tác | Kết quả mong đợi |
|---:|---|---|
| 1 | Nhập `10` vào First number | Giá trị `10` hiển thị đúng |
| 2 | Nhập `5` vào Second number | Giá trị `5` hiển thị đúng |
| 3 | Chọn Add | Add được chọn |
| 4 | Nhấn Calculate | Answer hiển thị `15` |

## Kết quả mong đợi cuối cùng

Ô Answer hiển thị `15`.

## Ghi chú

Có thể bổ sung dữ liệu số âm, số thập phân và giá trị biên trong test case khác.

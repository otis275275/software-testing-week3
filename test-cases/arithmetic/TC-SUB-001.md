## Mục tiêu

Xác minh hệ thống trừ chính xác hai giá trị số hợp lệ.

## Điều kiện tiên quyết

- Truy cập được trang Basic Calculator.
- Chọn build cần kiểm thử.
- Nhấn **Clear**.

## Dữ liệu kiểm thử

| Trường | Giá trị |
|---|---|
| First number | 10 |
| Second number | 4 |
| Operation | Subtract |
| Integers only | Unchecked |

## Các bước thực hiện

| Bước | Thao tác | Kết quả mong đợi |
|---:|---|---|
| 1 | Nhập `10` vào First number | Giá trị hiển thị đúng |
| 2 | Nhập `4` vào Second number | Giá trị hiển thị đúng |
| 3 | Chọn Subtract | Subtract được chọn |
| 4 | Nhấn Calculate | Answer hiển thị `6` |

## Kết quả mong đợi cuối cùng
